Place your logo and founder images here to use them in the site.

Accepted filenames (used by the app):
- `logo.png` — site logo used in the header (recommended: 512x128 px, PNG with transparency)
- `nabi.png` — image for CEO (recommended: square 400x400 px)
- `saddam.png` — image for CTO (recommended: square 400x400 px)

How to add:
1. Create the `public/assets` directory if it doesn't exist.
2. Copy your image files into `public/assets` using the exact filenames above.
3. Commit and push the changes. The preview/build will use these local assets automatically.

Notes:
- The app falls back to remote placeholder images if local files are not present.
- For best results, optimize images for web (resize + compress) before adding.
